# Google, IA e energia nuclear

O [prompt-base.md](prompt-base.md) é o prompt ativo deste projeto. Ele preserva o conteúdo de [prompt-editorial-original.md](prompt-editorial-original.md) e acrescenta a direção visual: `animateImages: true` para zoom e fades, `visualEffect: "shake"` apenas em poucos momentos pertinentes, e `particles` quando couber. O projeto salvo já usa `animateImages: true`; nenhuma cena recebeu shake automaticamente. O agente deve conferir a montagem antes de alterar o manifesto.
